# Карточка товара Teaboom.ru

Тестовое задание: верхняя часть карточки **Ананасовый улун**.

[Страница товара на сайте](https://teaboom.ru/product/ananasovij-ulun)

## Что сделано

- изображение, название, категория, фасовка, артикул, цены, кнопка «В корзину», краткое описание;
- при выборе фасовки обновляются цена, старая цена, артикул и активное состояние кнопки;
- у кнопки «В корзину» отдельные обычное и hover-состояния (корзина не подключена);
- адаптив под 1440 / 768 / 375.

## Запуск

Можно открыть `index.html` в браузере.

Либо локальный сервер:

```bash
npm start
```

Страница: http://localhost:4173

## Стили

Исходники — `scss/styles.scss`, в проект уже собран `css/styles.css`.

Пересборка:

```bash
npm install
npm run build:css
```
