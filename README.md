# Карточка товара Teaboom.ru

Тестовое: верхняя часть карточки «Ананасовый улун».

Ссылка на оригинал: https://teaboom.ru/product/ananasovij-ulun

## Что сделано
- Картинка, название, категория, фасовки, артикул, цены
- При смене фасовки меняются цена, старая цена и артикул
- Кнопка «В корзину» (просто уведомление, корзина не подключена)
- Адаптив 1440 / 768 / 375

## Как запустить
Просто открыть `index.html`
или
`npm start` → http://localhost:4173

Стили лежат в `scss/`, собранный файл — `css/styles.css`.
